## 一句話總結

> **清楚的意圖 × 相信自己值得 × 具體的下一步 × 持續的覺察 = 顯化**

純粹「想像成功、等宇宙送來」在研究中反而會**降低**行動力；但把正向想像和現實障礙、具體計畫結合起來，達成率會顯著提升。這份手冊保留顯化中真正有用的部分（意圖、信念、專注、情緒狀態），並補上讓它落地的行動機制。

## 5 分鐘快速開始

1. 寫下一個你最想在 90 天內實現的願望（一句話）。
2. 閉眼想像它實現時**最美好的畫面**，以及那一刻的感受（1 分鐘）。
3. 問自己：「**我內在最大的阻礙是什麼？**」（通常是一個念頭、情緒或習慣）
4. 寫下：「**如果**＿＿＿（阻礙）出現，**那麼我就**＿＿＿。」
5. 決定今天就能做的一個最小行動，然後去做。

這就是 WOOP，詳細說明見 [02](02-顯化方法工具箱.md)。
